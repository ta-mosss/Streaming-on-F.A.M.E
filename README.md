# Streaming on F.A.M.E — V5 Showcase

**Your Stage. Your Story.**

V4 is a production-minded public showcase for the future F.A.M.E entertainment platform. It preserves the existing concept catalogue, brand assets, waitlist endpoint, Plausible analytics hooks and GitHub Pages deployment while upgrading the experience into a cinematic, interactive product story.

## What changed in V5 — "Cinema"

The showcase now looks and behaves like a streaming product, so visitors experience the future VOD app rather than read about it.

- **Cinematic hero carousel** — five full-bleed featured titles with Ken Burns motion, pointer parallax, auto-advance with progress bars (pauses on hover/focus), and a "Coming 2027" platforms bar.
- **Streaming-style rails** — "Most anticipated" Top 10 with giant outlined numerals, plus Originals, Series, Films & Docs and Kids rails with hover lift, quick-play and My List buttons.
- **Interactive app preview** — a scaled Smart TV UI (Home, Originals, My List, Profiles) and a phone UI. My List is shared between the page, the TV and the phone, and persists in localStorage. "Cast" resumes the show on the TV.
- **Concept player** — simulated trailer with scrubber, captions and an end-card that routes to the waitlist (clearly labelled as not a live stream).
- **Feature bento, "why F.A.M.E" comparison, creator studio mock-up, roadmap and waitlist** — all clearly marked planned / concept.
- **Original key art** — 12 poster + 12 widescreen scenes generated by `scripts/generate-art.mjs` (no stock photography, no licensing risk). Edit the scenes and run `npm run art` to regenerate.
- Mobile-first layout, sticky mobile CTA, scroll progress, keyboard shortcut (`/` opens search), focus trapping in dialogs, `prefers-reduced-motion` support.
- Existing waitlist endpoint, Plausible analytics hooks, GitHub Pages deployment and honest product messaging are unchanged.

## Run locally

```bash
npm ci
npm run dev
```

Validate production:

```bash
npm run typecheck
npm run build
npm run preview
```

## Environment variables

Optional waitlist endpoint:

```text
VITE_WAITLIST_ENDPOINT=https://your-api.example/waitlist
```

Optional Plausible analytics:

```text
VITE_PLAUSIBLE_DOMAIN=streamingonfame.co.za
VITE_PLAUSIBLE_SCRIPT=https://plausible.io/js/script.js
```

Without the waitlist endpoint the form remains explicitly in demo mode and does not pretend to save an email.

## Architecture

```text
src/
├── data/catalogue.ts   # concept content model (poster + widescreen art, accents, badges)
├── analytics.ts        # privacy-friendly analytics hook
├── main.ts             # showcase application + interactions
└── styles/main.css     # V5 design system and responsive UI
scripts/generate-art.mjs # procedural key-art generator (npm run art)
public/assets/
├── brand/
└── content/
```

The future production application should remain separate and can own authentication, subscriptions, payments, playback, DRM, CDN, CMS, content ingestion, apps, Smart TV experiences and creator tooling.

## Product truth

This repository is a showcase. It does not claim that accounts, subscriptions, production streams or the displayed concept catalogue are live. Pricing and launch timing are targets only.
